# Client Site Starter

A reusable Astro starter for small-business client sites. Clean design tokens, accessibility-first defaults, and SEO/AEO baked in from the first commit — built to be re-themed per client rather than rebuilt from scratch each time.

## Using this template for a new client

Don't clone this repo directly. Instead:

1. Send the client `SETUP.md` — it walks them through creating their own GitHub + Vercel accounts and generating their own repository from this template via GitHub's **"Use this template"** button.
2. Once their repo exists and you're added as a collaborator, fill out `INTAKE.md` with them to scope the build.
3. Follow `CLAUDE.md` for build conventions, design tokens, and the decision trees for forms/scheduling/payments/gallery.

## Local development

```sh
npm install
npm run dev
```
